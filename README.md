# TendMyStore — WooCommerce Store Manager

Run your WooCommerce store from Claude: add and edit products, update prices and stock, handle orders and refunds, manage customers and coupons, adjust shipping and get sales reports, with a preview before every important change.

## Use it

1. Install the plugin, then connect TendMyStore for WooCommerce using Claude's connection and authentication flow.
2. Ask Claude in plain words, for example: "Which products are low on stock in my WooCommerce store, and what sold best last month?"
3. Claude uses the included skill: it looks first, shows what it plans to change, and asks for your approval before making changes.

## Data

This bundle contains instructions and a reference to the existing remote connector at https://mcp.tendmystore.com/mcp. Tool requests are handled by TendMyStore (https://tendmystore.com/privacy/). This bundle contains no separate storage service.
